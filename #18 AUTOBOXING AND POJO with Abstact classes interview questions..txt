Interview mein simple answer

Agar interviewer puche "Why should the public class name be same as filename in Java?", tum bol sakte ho:

"Java uses this rule so that the compiler can easily identify and locate the public class from its .java file."

Aur "Why only one public class per file?"

"Because a Java file can have only one public top-level class, and that class's name must match the filename, which gives Java a clear structure for locating public classes."
